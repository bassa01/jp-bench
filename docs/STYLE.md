# Style guide for task instructions

- Japanese instructions use です/ます form and short sentences.
- English instructions use imperative mood ("Search the publication site ...") and avoid "please".
- State the exact output in the last line of the instructions, as JSON keys.
- Gloss every administrative term on first use (see docs/GLOSSARY.md).
- Do not describe the answer. Describe where to look and what to return.
- Never ask the agent to bypass a login, CAPTCHA, or bot check.
