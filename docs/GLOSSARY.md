# Glossary of Japanese administrative terms

| Japanese | Reading | English gloss |
|---|---|---|
| 法人番号 | ほうじんばんごう | corporate number (13 digits, issued by the National Tax Agency) |
| 適格請求書発行事業者 | てきかくせいきゅうしょはっこうじぎょうしゃ | qualified invoice issuer (registered under the invoice system) |
| 登録番号 | とうろくばんごう | registration number (T + 13 digits for invoice issuers) |
| 令和 / 平成 / 昭和 | れいわ / へいせい / しょうわ | Japanese era names (Reiwa from 2019, Heisei 1989–2019, Showa 1926–1989) |
| 元年 | がんねん | first year of an era |
| 条 / 項 / 号 | じょう / こう / ごう | article / paragraph / item in a statute |
| 之 (の) | の | suffix used in article numbers, e.g. 第3条の2 |
| 附則 | ふそく | supplementary provisions attached to a law |
| 36協定 | さぶろくきょうてい | labour-management agreement on overtime (Article 36 of the Labor Standards Act) |
| 補助金 | ほじょきん | subsidy |
| 公募 | こうぼ | public call for applications |
| 送信 / 提出 | そうしん / ていしゅつ | submit (the final button that files a form; agents must not press it here) |
| 確認画面 | かくにんがめん | confirmation screen shown before submission |
| 株式会社 | かぶしきがいしゃ | stock company (abbreviated as (株) or ㈱) |
| 有限会社 / 合同会社 | ゆうげんがいしゃ / ごうどうがいしゃ | limited company / limited liability company |
| 一般社団法人 / 一般財団法人 | いっぱんしゃだんほうじん / いっぱんざいだんほうじん | general incorporated association / foundation |
