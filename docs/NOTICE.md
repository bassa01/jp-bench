# Notice: data sources

JP-Bench tasks read from the following official sites. Gold answers are fetched from these sources at evaluation time; this repository does not redistribute their content.

- `egov-36kyotei-fill`: e-Gov電子申請 (https://shinsei.e-gov.go.jp/), operated by デジタル庁 (Digital Agency)
- `egov-law-article`: e-Gov法令検索 (https://laws.e-gov.go.jp/), operated by デジタル庁 (Digital Agency)
- `houjin-bangou-lookup`: 国税庁法人番号公表サイト (https://www.houjin-bangou.nta.go.jp/), operated by 国税庁 (National Tax Agency)
- `invoice-number-verify`: 国税庁インボイス制度 適格請求書発行事業者公表サイト (https://www.invoice-kohyo.nta.go.jp/), operated by 国税庁 (National Tax Agency)
- `jgrants-open-subsidies`: jGrants（補助金電子申請システム） (https://www.jgrants-portal.go.jp/), operated by デジタル庁 (Digital Agency)
